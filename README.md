# Hookah Guest Bot

Восстановленный проект Telegram-бота подбора кальяна по сохранённой базе ассортимента и инструкции ИИ.

## Важно
Оригинальный Python-исходник среди доступных старых файлов не найден. Этот код — рабочая реконструкция по найденной инструкции и базе из 240 позиций. Он не выдаётся за оригинальный исходник.

## Структура
- `bot.py` — Telegram-бот на aiogram 3.
- `data/assortment.csv` — восстановленная база ассортимента.
- `requirements.txt` — зависимости.
- `render.yaml` — конфигурация Render Worker.

## Правила
- Бот использует только позиции из `data/assortment.csv`.
- Не придумывает бренды и вкусы, которых нет в базе.
- Если данных мало — задаёт до двух коротких вопросов.
- При подходящем запросе предлагает три варианта.
- Точные проценты забивки не придумываются.

## Запуск
```bash
pip install -r requirements.txt
export BOT_TOKEN="токен_бота"
python bot.py
```

## Render
Создать Worker из репозитория, указать `BOT_TOKEN` в Environment Variables. Build: `pip install -r requirements.txt`. Start: `python bot.py`.
